# hero-sale

Custom **hero** block. Purpose: Full-width promotional sale banner with an offer heading, a list of category CTA pills, an optional live countdown and a legal line.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional background image (desktop picture, then optional mobile crop); offer heading; one paragraph per category CTA link; optional end date paragraph in MM/DD/YYYY hh:mm:ss AM/PM format (rendered as a live countdown and hidden after expiry); legal text paragraph.

## Supported variations

No variations.
