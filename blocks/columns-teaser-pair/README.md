# columns-teaser-pair

Custom **columns** block. Purpose: Two equal portrait image teasers side by side, each with an overlaid title and CTA, stacking on mobile.

Single block table. Content: one row with one cell per teaser; each cell: image (desktop picture, then optional mobile crop), h2 title, SHOP NOW link.
